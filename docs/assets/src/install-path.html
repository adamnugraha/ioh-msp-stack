Getting it running

From an empty server to the first customer, one checked stage at a time

1
Optional, any Linux box

Try it in a lab

Two sample customers and 15 end-to-end checks

./lab/run-lab.sh
2
Once, with sudo

Prepare the server

Ubuntu updates, Docker, address pool, firewall

sudo ./scripts/prepare-server.sh
3
20 to 45 minutes

Install the core

Every stage checked; a failure says why and how to go on

./scripts/install.sh
4

Open it to staff

HTTPS, certificates, Keycloak and the console

install.sh proxy · sso · console
5
When you want them

Turn on the extras

Chat alerts, staff sign-in to the tools, dashboards, a model

install.sh chat · grafana · ai
6
Then every customer

Add the first customer

Secrets on the server, then a tenant in Nautobot

add-customer-secrets.sh acme
